jQuery-shaped DOM code, morphed instead of rebuilt. An update that

keeps nodes by key keeps your listeners keeps what users typed patches attributes in place awaits its transition

df$ selects real elements with native CSS selectors and returns them as a real Array. Content writes such as html(), text() and empty() go through the defuss-morph engine, which diffs the new content against the live DOM and patches it in place. Events and forms stay native: addEventListener and FormData.

<script type="module">
  // html() runs defuss-morph, not innerHTML: the list is
  // patched in place, both <li> are kept and reordered
  df$("#list").html('<li key="b">B</li><li key="a">A</li>');
  df$("#list li")
    .addClass("ready")
    .on("click", (e) => { df$(e.currentTarget).text("Saved"); });
</script>

One callable df$

Call it to select: CSS selectors, markup, VNodes, elements or collections. Read it as a namespace: df$.morph() and every other morph export sit on the same function.

Morph, not innerHTML

Content writes are diffed against the live DOM. Keyed and id-matched nodes are moved, not recreated, so their listeners and typed values survive, and focus stays on an element that keeps its place.

Real Arrays, fixed membership

A selection is an Array subclass: map, some and for...of just work. Its members are fixed when it is created; traversal returns a new selection, setters return the same one.

Native events

on() is addEventListener on each target, so stopPropagation(), non-bubbling events and currentTarget behave as usual. When morph removes an element, its listeners go with it.

Native forms

form() returns the browser's own FormData with duplicate names, files and the submitter; serialize() URL-encodes its string entries. No hand-rolled form walker.

Small and import-safe

The CDN bundle is 4.2 kB gzipped, imports nothing and does not embed morph. The npm entry writes no global and reads no document on import.

Live demo

A task board that re-renders on every change

Every change renders the whole list again as VNodes with df$("#tasks").morph(rows). Shuffle, sort or reverse it: the number on each row names its DOM element and does not change, because morph moves the keyed rows instead of rebuilding them. The inspector counts the elements each render kept, created and removed. The frame runs the bundles this site serves, with shadcn styles and no other script.

How it works

A facade over one engine

defuss-query adds no second reconciler and no second event system. It selects with the platform, writes content through defuss-morph and does the exact inserts and removals morph has no primitive for. The design rationale is in ARCH.md (opens in a new tab).

Call df$ to select

Every call returns a DfQuery: an Array subclass, deduplicated, in encounter order.

df$(".card")                 // querySelectorAlldf$("button", dialog)        // with a context rootdf$("<li>New</li>")         // parse markup into nodesdf$({ type: "b", children: ["x"] }) // render a VNodedf$(element) / df$(nodeList) // wrap targetsdf$(() => start())           // run when the DOM is ready

Read df$ as a namespace

The morph API is copied onto the function, plus three reserved slots.

df$.morph(el, "<p>Hi</p>")   // the engine itselfdf$.renderMarkup(vnode)       // any other morph exportdf$.fn                        // DfQuery.prototypedf$.dom                       // the structural adapterdf$.queryVersion              // the package version string

The write path of html()

  1. 01

    Parse

    A markup string becomes VNodes through morph's parser; standalone <tr>, <td> or <option> get their table or select context. VNodes and DOM nodes are snapshotted as VNodes.

  2. 02

    Diff

    morph() compares the VNodes with each element's live children. Nodes matched by key or id are moved; attributes are patched in place.

  3. 03

    Clean up

    Elements morph removes run its cleanup, and a hook defuss-query registers removes their on() listeners. Matched elements keep theirs.

  4. 04

    Return

    Without transition the call is synchronous and returns the selection for chaining. With one it returns a Promise of the selection, after every element's transition settled.

API

The whole surface on one page

The declarations ship in the package (dist/index.d.ts); the agent-facing reference is SKILL.md (opens in a new tab), which ships in the npm package too.

A string starting with < (after whitespace) is markup; any other string is a selector. Collections must contain EventTargets; anything else throws a TypeError.

df$("<markup>"), df$(vnode)DfQuery<Node>New detached nodes; several roots allowed.
df$(target | targets)DfQuery<T>Wraps an EventTarget (element, document, window) or an iterable or array-like of them.
df$(fn)DfQuery<Document>Runs fn(df$) on DOMContentLoaded, or in a microtask when the document is already parsed.
df$(), df$(null)DfQueryAn empty selection.
[i], .length, .get(i?), .toArray()item or arrayArray access; get() and toArray() return copies, get(-1) counts from the end.
.eq(i), .first(), .last()new selectionOne item; negative indices count from the end.
.each(fn)thisjQuery order (index, element) with this bound to the element; returning false stops.
.find(css), .filter(css | fn), .is(css)selection, booleanDescendants, matching subset, any match. .find(fn) keeps the native Array behavior.

.map(), .slice(), .flat()plain ArraySpecies-based Array methods return ordinary arrays.

Getters read the first element; setters write every element and return the selection. Non-element targets are skipped where a method needs an element.

MethodSemantics
.attr(name, value?)A missing attribute reads null, an empty selection undefined. Setting null removes it.
.prop(name, value?)Native JS properties. innerHTML, outerHTML, textContent and innerText writes throw: use the content methods.
.data(name, value?)dataset with camelCase keys; values are strings, null deletes. No cache, no JSON coercion.
.css(name | map, value?)Getters read the computed style, setters write inline style. camelCase and custom properties work; no implicit px.
.addClass(), .removeClass(), .toggleClass(names, force?), .hasClass()Whitespace strings or string arrays. removeClass() without arguments clears the attribute.
.val(value?)Control values; a multiple select reads and writes string arrays, an array on checkboxes and radios sets checked by value. Dispatches no input or change.

Content methods accept markup strings, VNodes, nodes, NodeLists and fragments. With several targets, nodes are cloned for all but the last target, which receives the originals.

MethodReturnsSemantics
.morph(content, options?)this or Promise<this>Morphs the content into every element. Passing transition makes it async, even { type: "none" }.
.html(content?, options?)string or as morph()Without arguments: the first element's innerHTML (its open shadow root's for normal elements). With content: morph().
.text(value?)string or thisReads the concatenated text. Writes literal text, never parsed as HTML; Text and CDATA nodes keep their identity.
.empty()thisMorphs an empty list into every element.
.append(), .prepend(), .before(), .after()thisExact inserts with insertBefore. A batch that would insert an ancestor into its descendant throws before any write.
.replaceWith(content)thisInserts the content before each target, then removes the target.
.appendTo(target)inserted nodesAppends this selection to a selector, root or collection and selects the inserted nodes.
.remove()thisDetaches every node after running morph's cleanup, which also removes on() listeners.
MethodSemantics
.on(types, handler, capture?)addEventListener on each target; space-separated types; this is the target. Only capture is accepted (true or { capture: true }); other option keys throw. For elements it needs morph loaded.
.off(types?, handler?)Removes listeners that on() added: by handler, by type, or all. Native and VNode listeners stay.
.trigger(type, detail?)Dispatches a CustomEvent built in the target's realm: bubbles and cancelable true, composed false. Not trusted input, no default actions.
.form(submitter?)The native FormData of a selection that is exactly one form, built with the form's own realm; otherwise throws. A submitter adds its entry.
.serialize(submitter?)URL-encoded string entries of form(); file entries are skipped.
NameSemantics
df$.<morph export>Every own export of the morph API, with its identity: df$.morph, df$.renderMarkup, df$.queueCallback and the rest.
df$.fnDfQuery.prototype, for adding your own chain methods.
df$.domThe structural adapter: create, insert, replace, remove, morph, text.
df$.queryVersionThe package version string.
createDf$(morphApi)From defuss-query/core: a new df$ around the given morph API.

Install

Add it to a page or a project

Two script tags for a page, or the npm package with its defuss-morph peer for a build. Or hand one prompt to your coding agent.

In a page

Load morph first, then query. Module scripts run in document order, so the application script after them sees df$.

defuss-query.min.js defuss-morph.min.js

In a project

The npm entry imports the defuss-morph peer (^0.2.0) and has no side effects on import, so server-side imports are safe.

With a coding agent

Paste this prompt into your coding agent. The package ships SKILL.md, the API reference written for agents.

Use defuss-query for the DOM code in this app: https://github.com/kyr0/defuss-query
Install defuss-query and defuss-morph, then read node_modules/defuss-query/SKILL.md and follow it.
Write content with html(), text() or morph() instead of innerHTML, render lists as keyed VNodes, and put user input only into text() or VNode text.
Use on() and off() for listeners and form() for form data.
